# 1.20.0.3

**Release Date:** 2026-10-01
**Official Announcement:** https://store.steampowered.com/news/app/1158310/view/684140727200907566

---

Hello everyone! We're pushing a small hotfix today ahead of the weekend to tackle some high priority issues reported to us since the release of By God Alone. We're continuing to work on additional issues that have been reported, and those fixes will be deployed at a later date.


Check the changelog below for more information!


---


### Update 1.20.0.3 Changelog

-   Fixed a bug where all candidates to an elective title were prevented from being granted a title. Now only the candidate that is currently winning is blocked from being granted a title directly
-   Fixed a crash that can occur in the Frankokratia fourth crusade story
-   Chalcedonians are now properly counted as involved in the Iberian struggle
-   Fixed a bug where nomads could not reform faiths 
-   Fixed Coronation doctrines blocking rite editing if you did not have the Coronations DLC
-   Fixed a bug where creating a head of faith title as a non-christian would leave you without an heir
-   Fixed a bug where pilgrimages cost treasury for non-christian theocrats who don’t have treasury
-   Fixed a bug where travel contracts would invalidate upon arrival
-   Fixed the By God Alone UI skin string in the settings


---


As always, if you encounter any issues after today's update, please ensure you have disabled _all_ mods and file a report [via our Bug Report forum](https://forum.paradoxplaza.com/forum/forums/crusader-kings-iii-bug-report.1143/) if the issue persists.
