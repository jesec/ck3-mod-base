# 1.19.0.5

Hello everyone! We’re releasing a small bugfix update today to address some outstanding issues since the release of 1.19 “Scribe.” Check the changelog below for more information!


---


## Update 1.19.0.5 Changelog


### Bugfixes

-   Fixed an issue where the Legendary Hunt Story Cycle would not start despite starting a legendary hunt.


-   The Iberian Dominance ending can no longer be repeated infinitely for unlimited renown.


-   purchase_land_interaction now only allows duchy targets when the seller completely controls that duchy.


-   Custom title names are no longer reset to default in Title History after a ruler’s death.


-   AI characters can now upgrade their knight accolades.


-   Rites of Passage no longer refunds gold or prestige when cancelled.


-   Fixed an issue preventing “The Song of El Cid” Story Cycle from being finished.


-   Administrative rulers from the Renewed Caliphate ending now correctly get the Subjugation CB.


-   Characters at their concubine limit can now offer concubines to other characters.


-   Fixed an issue where the side buttons in the Character Panel wouldn't display correctly after loading a multiplayer save.


-   Japan now shows the correct title and government type when selecting a starting character.


-   Characters in a travel entourage now reset to their original location if their travel plan is cancelled.


-   Your infidelity will no longer be broadcasted to everyone as it happens. It’s the Middle Ages, not a Coldplay concert.


    -   Note: Pregnancies that began in 1.19.0.4 will still trigger this!


-   Fixed bug where using the "Purchase Land" interaction as Landless would not distribute the land properly to the purchaser
