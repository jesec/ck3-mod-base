# CK3 Vanilla Administrative Estate — Export

Source: https://github.com/besbesbechir93-cyber/ck3-mod-base (base/game)
Tracked CK3 version: 1.20.1.1 (Crozier)

The source files are copied by their original Git blob SHAs and organized with game-root-relative paths. This bundle includes Administrative Estate scripts, shared domicile UI, administrative mechanics, associated events, localisation in all available languages, and relevant GFX paths. Shared files may also contain other vanilla mechanics: their content is unchanged.

**GFX warning:** The source repository excludes actual binary graphics and stores metadata placeholders (JSON text) in .dds/.png paths. These ARE NOT renderable images. Recover genuine graphics from a legitimate CK3 installation. No texture images have been fabricated.

This is a reference extraction, not a directly playable CK3 mod. Some generic game-engine dependencies are outside its scope. No changes were made to the vanilla source text.
